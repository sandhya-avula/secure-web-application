# Secure Web Application

## Project Overview
A Python project demonstrating secure user authentication, password hashing, and access control.

## Technologies Used
- Python
- Flask
- SQLite
- Werkzeug
- Google Colab

## Features
- User registration
- Secure password hashing
- Login authentication
- Protected dashboard
- Logout functionality
- Automated security tests

## Security Measures
- Password hashes are stored instead of plain-text passwords.
- Parameterized SQL queries help prevent SQL injection.
- Password verification uses Werkzeug security utilities.
- Session-based access control protects the dashboard.

## How to Run
1. Open the `.ipynb` notebook in Google Colab.
2. Run the code cells in order.
3. Review the security test results.

## Limitations
This is an educational prototype tested using Flask's test client in Google Colab. It is not a production-ready or publicly hosted website.
